# MNIST Digit Classification using ANN

A beginner-friendly deep learning project that builds, trains, and evaluates an Artificial Neural Network (ANN) to recognize handwritten digits (0–9) using the classic **MNIST dataset**.

## 🚀 Features
* **Dataset:** MNIST handwritten digits (28x28 grayscale images).
* **Architecture:** Fully-Connected Feedforward Neural Network built with Keras (`Sequential` model).
  * Input Layer
  * Flatten Layer
  * Dense Hidden Layer (128 units, ReLU activation)
  * Dropout Layer (to prevent overfitting)
  * Dense Output Layer (10 units, Softmax activation)
* **Performance:** Achieves around **97.9% accuracy** on the test dataset. 

## 🛠️ Tech Stack
* Python
* TensorFlow / Keras
* NumPy
* Scikit-Learn
* Matplotlib
